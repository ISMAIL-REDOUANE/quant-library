Python books for trading: from basics to backtesting

Python can help organize data, test ideas and automate research. The starting book depends on whether you are learning the language or already understand the basics and want finance-specific applications.

First learn the language

Automate the Boring Stuff with Python is a general programming introduction, not a trading textbook. Variables, data structures and file handling are useful prerequisites.

Apply Python to trading

Python for Algorithmic Trading moves into financial data and backtesting. Its publisher describes it as intermediate to advanced; new programmers may benefit from learning the basics first.

Test carefully

Separate development data from evaluation data. Include realistic trading costs and execution constraints, and do not treat past performance as a guarantee.
